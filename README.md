# Qazaq Dama

> **Победи ИИ — встреться с чемпионом Казахстана.**
> *Қазақстаннан әлемге.*

Веб-платформа для игры в казахские/русские шашки с **Кубком Чемпионов** (главный приз сезона — личная встреча с шахматным гроссмейстером Казахстана), AI-тренером, мультиплеером по ссылке, лидербордом казахстанских городов и работающей Pro-подпиской через Stripe. Не «ещё один сайт для шашек», а нативно казахстанский продукт с собственным культурным мостом к шахматной школе Казахстана и доказанной монетизацией.

- 🚀 **Live:** [qazaq-dama.vercel.app](https://qazaq-dama.vercel.app)
- 💻 **GitHub:** [kuatbek1995/qazaq-dama](https://github.com/kuatbek1995/qazaq-dama)
- 🎓 Сделано для **nFactorial Incubator · 2026**

## О продукте

### Что мы сделали

Полноценный продукт, а не доска для шашек:

- **🏆 Кубок Чемпионов (киллер-фича):** каждый месяц-сезон ведёт один из 6 шахматных чемпионов Казахстана — **Бибисара Асаубаева**, Жансая Абдумалик, Динара Садуакасова, Дармен Садвакасов, Муртас Кажгалеев, Ринат Жумабаев. Игрок №1 на конец сезона получает **личную встречу с этим чемпионом** (формат, место и дата согласуются с победителем). Очки начисляются только за победы над AI Сложный (1 победа = 1 очко) с анти-фарм защитой через CHECK constraint в Postgres + минимальный порог 8 ходов и 30 секунд. На главной странице — большая золотая кнопка «▶ Играть за приз» одним кликом запускает квалифицирующую партию. Это превращает шашки в bridge к шахматной культуре Казахстана и даёт уникальную причину возвращаться каждый день — у chess.com / lichess / draughts.org такого нет.
- **Игра:** полные правила русских шашек (диагонали, обязательные взятия, длинная дамка, multi-jump). Hot-seat вдвоём за одним экраном. AI-противник с тремя уровнями сложности и **недетерминированным выбором ходов** — играет каждую партию по-разному.
- **Мультиплеер по ссылке:** Supabase Realtime — создаёшь партию, отправляешь URL другу, играете в реальном времени с синхронным таймером и чатом со стикерами. В сайдбаре рядом с именем соперника показывается 👑, если у него Pro.
- **AI-тренер (Gemini):** после партии разбирает игру на твоём языке («на 5-м ходу ты упустил двойное взятие») — реально полезный фидбек, а не общие фразы про шашки.
- **Лидерборд городов:** 20 казахстанских городов соревнуются между собой. Каждая выигранная партия против AI идёт в общий счёт + рейтинг твоего города.
- **Pro-подписка через Stripe ($2/мес):** реальная интеграция в test mode. Жюри может «купить» Pro тестовой картой `4242 4242 4242 4242` и сразу увидеть как разблокируются премиум-фишки (3 эксклюзивные темы доски: Юрта, Степь, Тенгри + корона рядом с именем).
- **i18n:** интерфейс полностью переведён на **English / Русский / Қазақша**. AI-тренер тоже многоязычный — Gemini получает локаль и отвечает на нужном языке.
- **Звук:** атмосферная музыка на меню и в игре + звуки ходов и взятий, с переключателем mute.
- **UX-полировка:** Framer Motion анимации, конфетти на победе, авто-выбор языка при первом визите → авто-открытие модалки знакомства, профиль-меню с аватаром и выходом.

### Для кого

**Основная аудитория:** игроки 18-35 лет в Казахстане и казахстанской диаспоре по всему миру. Те, для кого шашки — часть культуры детства, но кто не находит достойного продукта на родном языке с национальной эстетикой.

**Три персоны:**
1. **Casual игрок** — хочет быстро сыграть с другом, не разбираясь в правилах международных draughts.
2. **Растущий игрок** — хочет понять, где он ошибся, и расти. Платит за безлимит AI-разбора в Pro.
3. **Соревновательный игрок** — хочет видеть имя своего города в топе. Городская гордость = retention.

### Почему это ценно

- **🏆 Уникальный приз = настоящая differentiation:** Кубок Чемпионов с личной встречей с шахматистом — это **то, что нельзя скопировать** международным конкурентам. Это требует культурного контекста Казахстана и прямой связи с местными гроссмейстерами. Жюри спрашивают «чем вы отличаетесь от chess.com?» — у нас есть конкретный ответ.
- **Локальное позиционирование:** существующие сайты (chess.com, шашки.com) — утилитарные, безличные, без культурного контекста. Мы первые делаем шашки **С** Казахстана и **ДЛЯ** Казахстана.
- **Сетевые эффекты:** каждая мультиплеер-партия = +1 потенциальный пользователь (получатель ссылки). Лидерборд по городам + турнирная таблица Кубка создают **региональную и национальную ривалрию** одновременно.
- **AI как реальный moat:** мы используем LLM (Gemini) на актуальных данных партии — это сложно повторить и легко расширять (персонализированные планы тренировок в Pro v2).
- **Доказанная монетизация:** работающий Stripe от первого дня — не «когда-нибудь сделаем», а уже сейчас можно подписаться. Это разница между MVP и игрушкой.

### Сверх ТЗ

- **🏆 Кубок Чемпионов** — реальная встреча с шахматным гроссмейстером как награда, ротация 6 чемпионов по сезонам, динамическая «Цель» (сколько очков надо набрать до конкретной даты), серверная защита от фарма через Postgres CHECK constraint. Этого нет ни у chess.com, ни у lichess, ни у одного существующего checkers-сайта.
- **i18n на 3 языка** с локале-aware AI-коучем (включая локализованную дату окончания сезона: «May 31» / «31 мая» / «31 мамыр»)
- **Pro фичи действительно работают** — премиум-темы доски применяются мгновенно, корона видна сопернику в мультиплеере
- **Недетерминированный AI** — каждая партия против ИИ непредсказуемая (epsilon-пул лучших ходов со взвешенным выбором)
- **Безопасная Pro-верификация:** `/api/checkout-verify` дёргает Stripe API проверить, что сессия реально оплачена, перед сохранением статуса
- **Профиль-меню:** одна круглая кнопка вместо россыпи — клик открывает дропдаун с языком, профилем и выходом (полный wipe данных при logout — следующий пользователь на устройстве не наследует Pro)

## Демо для жюри (3 минуты)

1. Откройте https://qazaq-dama.vercel.app в инкогнито
2. Выбираете язык в авто-модалке → пишете имя и город → попадаете в меню
3. **Hero сразу читается:** «Победи ИИ — встреться с чемпионом Казахстана»
4. **Главный визуальный элемент** — золотой блок «🏆 КУБОК ЧЕМПИОНОВ · Май 2026» с фото Бибисары Асаубаевой, плашкой «Личная встреча с чемпионом сезона» и синей плашкой «🎯 Цель: набери больше всех очков до 31 мая»
5. Клик «▶ Играть за приз» (большая золотая кнопка) → **в одно касание** запускается AI на «Сложном» — единственный режим, дающий очки в Кубок
6. Играете партию (≥8 ходов, ≥30 сек) → выигрываете → видите анимированный **золотой бейдж «+1 очко в Кубок Чемпионов»** + конфетти + Gemini-разбор партии
7. Жмёте «Все чемпионы →» → попадаете на `/champions` со стеной 6 шахматных легенд, биографиями, FIDE-рейтингом и турнирной таблицей текущего сезона
8. Возвращаетесь в меню → **Upgrade to Pro** → вводите тестовую карту:
   - `4242 4242 4242 4242`, дата `12/30`, CVC `123`, email любой
9. Stripe принимает → редирект → конфетти → авто-открывается выбор темы доски
10. Применяете **Тенгри** (космический синий) → возвращаетесь в меню → видите 👑 рядом с именем
11. Переключите язык в профиль-меню → весь UI, Кубок и AI-разбор автоматически на другом языке (включая локализованную дату «May 31» / «31 мая» / «31 мамыр»)

Всё работает на проде. Никаких dev-only фич.

## Стек

- **Frontend:** Next.js 16 (App Router, Turbopack) + React 19 + TypeScript
- **Стили:** Tailwind CSS v4 + кастомная казахстанская палитра (золото `#f0c14b` + KZ-blue `#00afca`)
- **Анимации:** Framer Motion 12, canvas-confetti
- **Backend:** Supabase (Realtime channels для мультиплеера + Postgres `scores` с RLS для лидерборда)
- **AI:** Google Gemini Flash (`gemini-flash-latest`) — бесплатный tier, многоязычный промпт
- **Платежи:** Stripe (test mode) — subscription с `mode: "subscription"`, серверная верификация через `stripe.checkout.sessions.retrieve()`
- **Деплой:** Vercel (авто-деплой из main)
- **Иконки:** Lucide React

## Архитектурные решения (для тех, кто заглянет в код)

- **Кубок с серверной защитой от фарма:** [`src/lib/cup-scores.ts`](src/lib/cup-scores.ts) + [`supabase/champions-cup-schema.sql`](supabase/champions-cup-schema.sql) — очки начисляются строго через CHECK constraint `mode = 'ai-hard' AND points = 1` в Postgres. Подменённый клиент не зальёт фейковые очки — Supabase отбросит INSERT. Плюс минимальный порог 8 ходов + 30 секунд в [`EndScreen.tsx`](src/components/game/EndScreen.tsx) — защита от моментальных сдач. Type-уровень тоже сузили: `CupMode = "ai-hard"` гарантирует на компиляции что в Кубок может попасть только этот режим.
- **Ротация чемпионов как чистая функция:** [`src/lib/champions.ts`](src/lib/champions.ts) — массив `CHAMPIONS[]` + `getChampionForSeason(season)` вычисляет индекс через `(monthsFromAnchor % CHAMPIONS.length)`. Никакой БД для чемпионов — расширение ротации = добавить элемент в массив. Дата окончания сезона локализована для EN/RU/KK через `getSeasonEndDateLabel()`.
- **Динамическая «Цель» в Cup-блоке:** [`src/components/CupBlock.tsx`](src/components/CupBlock.tsx) — текст «сколько очков надо» резолвится в 4 ветки (пусто / догоняешь лидера / лидер ты / без identity) на основе live-данных `fetchCupLeaderboard()`. Игрок всегда видит **актуальный** target, а не абстрактное «стань первым».
- **AI с пулом ходов вместо строгого argmax:** [`src/lib/checkers/ai.ts`](src/lib/checkers/ai.ts) — minimax с alpha-beta даёт оценку каждого хода, собираем все ходы в `epsilon`-окрестности лучшего, выбираем взвешенно. Результат: на одинаковой позиции AI отвечает по-разному.
- **Реалтайм без раздувания payload:** [`src/components/game/MultiplayerGame.tsx`](src/components/game/MultiplayerGame.tsx) — broadcast только хода/синка, а не всего состояния. Pro-статус игрока передаётся вместе с identity-событием.
- **i18n без отдельной библиотеки:** [`src/lib/i18n.tsx`](src/lib/i18n.tsx) — простой Context + `useT()` + словарь. Полная типизация, `localStorage` persistence, поддержка интерполяции `{name}`, `{date}`, `{points}`.
- **Серверная проверка оплаты:** [`src/app/api/checkout-verify/route.ts`](src/app/api/checkout-verify/route.ts) — нельзя «почувствовать себя Pro» простой подменой URL: бекенд спрашивает Stripe, оплачена ли сессия.
- **Темы доски через CSS-переменные:** [`src/app/globals.css`](src/app/globals.css) — `[data-board-theme="tengri"]` переопределяет `--board-light` / `--board-dark`. Переключение мгновенное, без перерендера React.

## Локальный запуск

```bash
git clone https://github.com/kuatbek1995/qazaq-dama.git
cd qazaq-dama
npm install
cp .env.local.example .env.local  # заполнить переменные (см. ниже)
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

### Переменные окружения

```bash
# Опциональные — без них работают одиночная игра и AI
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
GEMINI_API_KEY=AIzaSy...

# Опциональные — без них работает всё кроме Stripe Checkout
STRIPE_SECRET_KEY=sk_test_...
STRIPE_PRO_PRICE_ID=price_...
```

- **Supabase:** [supabase.com/dashboard](https://supabase.com/dashboard) → создать проект → Settings → API. После создания вставить `supabase/schema.sql` в SQL Editor.
- **Gemini:** [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → Create API key (бесплатно).
- **Stripe:** [dashboard.stripe.com](https://dashboard.stripe.com) → test mode → Developers → API keys. Цену создать через `POST /v1/prices` или в дашборде (Recurring, USD, $2/мес).

Приложение **деградирует gracefully**: без Supabase скрывает мультиплеер/лидерборд, без Gemini показывает «коуч недоступен», без Stripe кнопка покупки возвращает 503.
